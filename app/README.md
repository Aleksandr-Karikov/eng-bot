# Mini App (карточки в Telegram)

Веб-приложение с теми же карточками, что и `/learn`, но со свайпами: тап переворачивает, свайп
вправо/влево — «помню»/«забыл». React + Vite + `@telegram-apps/sdk-react` + `telegram-ui`.
Использует ту же очередь и тот же FSRS, что и бот, — прогресс общий.

## Как это устроено

Собранное приложение отдаёт **сам бот**, отдельного сервера нет:

- `app/dist/` раздаётся по `/app/` (`src/app/server.ts`, `serveStatic`);
- API живёт рядом, на `/api/*`;
- кто пользователь — определяется **только по подписанным данным запуска Telegram** (`initData`),
  проверка через `@telegram-apps/init-data-node`. Своих логинов и паролей нет. Открыть приложение
  можно лишь из бота — иначе API отвечает 401 «Открой приложение из бота».

Наружу бот выставлен через ngrok: `/app/` — приложение, `/ext/*` — приём слов из расширения
(один туннель на оба). Адрес задаётся `APP_URL` в `.env`; бот добавляет кнопку «📚 Учить» только
когда `APP_URL` задан.

## Сборка и запуск

```bash
cd app
npm install
npm run build      # tsc --noEmit && vite build → app/dist
```

`base` в `vite.config.ts` — `/app/`, менять его нельзя: по этому префиксу бот раздаёт статику.
`npm run dev` поднимает Vite отдельно, но API всё равно придётся проксировать на бота, а `initData`
вне Telegram не приходит — так что для проверки всё равно нужно открыть приложение в Telegram.

Порядок для боевого запуска:

1. Правите фронтенд → `cd app && npm run build`. **Обязательно:** бот раздаёт только `dist`,
   а он в `.gitignore` и в репозитории не лежит.
2. `cd app && npm run typecheck` — при правке типов. У `app/` свой `tsconfig.json`, корневой `tsc` его не покрывает.
3. `scripts/launchd/restart.sh` — бот подхватит новый бандл.

## Проверки

- `npm test` из корня — там же `tests/mini-app.test.ts` и `tests/app-typed.test.ts` (API приложения,
  подпись `initData`, ответы на 401).
- Язык ответов API берётся из текущей комнаты пользователя — как в боте, через `withLang()`
  (`src/app/server.ts`). Забыть об этом — типичная ошибка при добавлении нового эндпоинта.
