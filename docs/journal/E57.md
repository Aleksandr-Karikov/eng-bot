# E57 — Бой со Стражем за энергию во всех комнатах

## Спека

Открыть механику E56 всем пользователям режима босса. Личный выбор накопления энергии сохраняется.
Вопрос доступен при открытом ядре Стража и достаточном запасе энергии. Telegram-авторизация и проверка
членства сохраняются.

Вопрос открывается участникам любой подходящей комнаты без настройки сервера. Другие боссы используют
обычную атаку. Расход и повтор запроса проверены.

## Что сделано

- Удалена настройка с ID комнаты. Ядро Стража во всех комнатах работает через вопрос на перевод.
- Ядро открывается на половине HP текущего Стража. Попытка учитывается за текущий бой.
- Обычный ручной удар по Стражу расходует до 10 энергии. Руна усиливает обычный удар.

## Решения и ограничения

- Уже записанные удары и балансы сохраняются. Новый вопрос учитывается отдельно для каждого Стража.
- Для вопроса нужны четыре разных перевода и хотя бы одно ранее показанное игроку слово.

## Проверено

- Прошли профильные тесты босса, экрана и дуэлей, а также `npm run typecheck`.
- Подписанный API проверен на комнатах с разными ID. Проверены верный и неверный ответ, повтор
  запроса, обычный удар с руной и отказ при смене босса.
