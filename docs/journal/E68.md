# E68 — Арена за энергию с предзагрузкой графики

## Спека

Убрать бесплатную тренировку из Mini App и запретить её запуск через API. При открытии вкладки
босса загрузить и декодировать фон, героя, босса и реквизит его сцен. Заранее загрузить фон и
портрет противника следующего раунда. Платные сцены работают, отказ тренировки не расходует
энергию, проблема с картинкой не блокирует бой.

## Что сделано

- Экран предлагает бой за ставку. Старый запрос `mode: "practice"` получает `410` с подсказкой
  переоткрыть Mini App. Боевые попытки проходят через действующие проверки комнаты и леджер.
- Mini App готовит графику текущего босса при открытии вкладки. По готовности набора фоном
  загружает и декодирует изображения следующего босса по подсказке из API. Уже подготовленные
  изображения переиспользуются в открытом приложении.
- Вход в сцену переиспользует обещание декодирования. Пока ресурсы готовятся, остаётся
  предпросмотр. После ошибки картинки или истечения короткого ожидания доступны ходы.

## Решения и ограничения

- Предзагрузка начинается во вкладке босса, поэтому не расходует трафик при открытии обучения.
  Текущая сцена имеет приоритет перед фоном и портретом следующего раунда.
- После получения ответа о старте экран ждёт готовности картинки максимум 700 мс. При более
  медленной загрузке изображение может появиться во время боя. Встроенный браузер Telegram
  на телефоне отдельно не проверялся.

## Проверено

- `npm test`, `npm run typecheck`, `npm run lint`, `npm --prefix app run build` и `npm run docs:check`.
  Через подписанный API проверены отказ тренировки и повтор платного хода, подсказка следующего
  противника, оба платных сценария у всех боссов и урон после подъёма.
- Chrome с подписанными тестовыми данными на 320, 390 и 800 px в обеих темах. Графика текущей
  сцены запрашивалась до атаки, фон и портрет следующего босса загрузились до добивания. Пройдены
  замедленная загрузка, отсутствующая картинка, превышение времени ожидания, открытие боя при
  готовых картинках и нулевой баланс.
