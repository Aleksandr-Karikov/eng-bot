# E79 — Грамматика, сочетания и напоминание о заданиях

## Спека

В Mini App отправлять ответ видимой кнопкой (#28), возвращать поставленное слово (#29)
и сохранять сочетания из разбора (#26). Засчитывать три разных верных ответа
по грамматике за день. В личном напоминании дать ссылку на оставшиеся задания.
По просьбе владельца #27 закрыт как продуктовое замечание.

## Что сделано

- В сборке предложения слова с крестиком возвращаются в набор. Ручной ввод и Enter доступны.
  Кнопка «Проверить» отправляет собранную или набранную фразу и ответ на задание с пропуском.
- «В словарь» у сочетания в разборе запускает подготовку и сохранение по обычным API словаря.
  После сохранения или при существующем сочетании виден статус «В словаре».
- За три разных верных ответа в грамматике можно один раз забрать 10 ⚡. Используется один
  журнал для Mini App и чата. Учитываются ответы с момента обновления, день считается
  в часовом поясе пользователя, повтор упражнения в тот же день не добавляет прогресс.
- При незавершённых заданиях бот добавляет их прогресс и кнопку Mini App к личному напоминанию.
  Если карточек нет, сообщение содержит только задания. Время и защита от повторной отправки общие
  с существующим напоминанием. Применяется для пользователей с текущим словарём и доступной личкой.

## Проверено

- Прошли `npm test`, `npm run typecheck`, сборка Mini App и линтер.
  Генерация схемы подтвердила, что для нового значения журнала миграция не требуется.
- В Chrome на 320 px в тёмной теме и 800 px в светлой прошли возврат слова, проверка кнопкой
  и по Enter, повтор после отказа, переход из заданий в грамматику и обратно, получение награды
  и сохранение `overcome obstacles` с переводом.
- Тесты рассылки проверяют время пользователя, повтор при сбое доставки, единственное сообщение
  за день, кнопку с адресом Mini App и работу с очередью карточек и без неё. Используется
  тестовая доставка, реальные личные сообщения для проверки не отправлялись.
