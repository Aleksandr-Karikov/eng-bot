# E44 — Целевое слово открывается после ответа в диалоге

## Спека

После проверки [E43](E43.md) на продакшене убираем подсказку вида «Употреби claws — когти».
Mini App и `/learn` показывают ситуацию и реплику без готового слова. Подсказка доступна по
нажатию или под спойлером. Слово и перевод появляются в разборе, в том числе после «Не знаю».
Повторная попытка сохраняет возможность вспомнить слово самостоятельно.

## Что сделано

- «Подсказка» в Mini App показывает смысл и начало возможного ответа. В `/learn` оба доступны
  под спойлерами. Первая незачтённая попытка предлагает уточнить реплику и оставляет подсказку закрытой.
- Модель получает указание задавать конкретный вопрос, в котором нужный предмет, действие или
  качество центральны для ответа. При уместном ответе другой фразой отзыв признаёт, что смысл подходит,
  и предлагает уточнить деталь.
- Сервер проверяет реплику, начало ответа и отзыв перед повторной попыткой. Если сама сценка уже
  называет слово, доступна обычная карточка. Для проверки используются словарная форма и формы,
  которые распознаёт общий шаблон употребления слов.

## Проверено

- `npm test -- --reporter=dot`, `npm run typecheck`, `cd app && npm run build` и `npm run docs:check` прошли.
- Через подписанный Mini App API проверены отклонение сценки с раскрытым словом, скрытие слова
  в подсказке и отзыве, отсутствие оценки до повторной попытки и разбор после «Не знаю». Тестовый
  Telegram API подтвердил спойлеры и показ слова после ответа.
- В Chrome на 390 px в обеих темах и на 800 px в тёмной теме проверены открытие карточки, повторная
  попытка со скрытым словом, подсказка по нажатию и разбор. При имитации клавиатуры вопрос и поле
  поместились на экране. На этом прогоне использовалась тестовая модель.
