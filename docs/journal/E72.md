# E72 — Длинные интервалы освобождают места в «Учу»

## Спека

Карточки в состоянии повтора FSRS с назначенным интервалом от семи дней приходят по своему
расписанию вне предела «Учу». Срок и прогресс сохраняются. Освобождённые места получает обычная
очередь, дневная порция действует. Если после повтора карточке нужен короткий интервал, она
возвращается в подборку даже при полном лимите. В списке есть фильтр «Повторы» с датами.

## Что сделано

- Отбор в «Учу» и обычную очередь повторов использует назначенный интервал из сохранённой
  карточки FSRS. Правило действует и для ранее отложенных карточек с длинным интервалом.
- Короткий интервал после самостоятельного повтора возвращает слово в «Учу». Существующая
  отмена восстанавливает прежний интервал и место карточки.
- В Mini App слова на длинных интервалах видны в «Словах → Повторы» вместе с выученными.
  У них своя подпись «по графику». Настройки и «Учу» поясняют, когда освобождается место.

## Решения и ограничения

- Порог относится к полному назначенному интервалу. Поэтому слово остаётся доступным для
  обычного повтора при приближении срока и после его наступления.
- Прогресс и даты берутся из существующих данных. Критерий «выучено» и дневная порция сохранены.
  При большом хвосте начатых слов свободные места сначала занимают карточки с короткими интервалами.

## Проверено

- Прошли `npm test`, `npm run typecheck` и `npm --prefix app run build`. Регрессия через подписанный
  API проверяет ранее сохранённый длинный интервал, доступ к новому слову в освободившемся месте,
  дневную порцию, повтор при полном «Учу», возврат после «Забыл» и отмену ответа.
- В Chrome с эмуляцией Telegram при 390 px в тёмной теме и 800 px в светлой проверены загрузка, отказ,
  пустой поиск и переход из «Учу» к повторам с датами. Длинный интервал виден в «Повторах».
- Запрос к продакшен-базе в режиме чтения подтвердил наличие назначенных интервалов на старых карточках.
