# E20 — В корейской комнате часть интерфейса и промптов остаётся английской

## Спека

Пока KO не выпилен, четыре расхождения давали неверный результат в корейской комнате:

1. `countDueSplit` не фильтровал по языку, хотя очередь `/learn` фильтровала — счётчик показывал
   «2 новых» при пустом `/learn`;
2. `sendWordsOfDay` вызывался вне `withLang` — корейское слово уходило с `🇬🇧 /sa-rang/` и кнопками
   «🔊 UK / US»;
3. `buildGrammarPrompt` — единственный сборщик без языковой ветки, давал корейскому слову английскую
   морфологию;
4. `listTopics` не фильтровал по языку, а KO-тем не было вовсе.

Приёмка: задачи не нужно отдельно, если E23 выполняется раньше — правки входят в него. Если E23
откладывается, чинить эти четыре места и закрывать здесь.

Решение владельца: чинить не порознь — язык убирается целиком в E23, эти расхождения закрываются там же.

## Что сделано

**Ничего отдельно.** E23 выполнена ([журнал](E23.md)), и все четыре расхождения исчезли вместе с языком,
потому что исчезло само условие их существования — второго языка.

Как именно закрылся каждый пункт:

1. **`countDueSplit`** — фильтровать больше не по чему: язык один. Функция считает карточки к повторению
   и новые, очередь `/learn` отдаёт их же. Совпадение счётчика и очереди проверяется существующими
   тестами очереди.
2. **`sendWordsOfDay`** — `withLang` не существует, контекст операции удалён. Текст слова дня всегда
   английский: `🇬🇧` и кнопки «🔊 UK / US» теперь верны по определению, а не по совпадению контекста.
3. **`buildGrammarPrompt`** — языковой ветки не осталось ни у одного сборщика: все говорят про
   английский явно. Пункт «единственный сборщик без языковой ветки» перестал быть особым случаем.
4. **`listTopics`** — фильтр по языку убран из `word-sets` и `grammar-topics`; темы одни и те же,
   делить их не на что.

## Проверки

Проверено на факте, а не на рассуждении:

```
grep -rn 'withLang\|currentLang\|inCurrentLanguage' src/   → 0 совпадений
grep -rn '"ko"' src app/src                               → 0 совпадений
npx vitest run                                            → 122 files, 857 tests passed
```

Три пробы из исходной задачи (которые её и открывали) теперь невозможны по построению:
`due={review:0,fresh:2}` при пустой очереди — потому что фильтра два, а языка один;
`☀️ … 🇬🇧 /sa-rang/` — потому что корейских слов в базе нет (миграция удалила их вместе с комнатами).

## Известные ограничения

- **Отдельных тестов на эти четыре места нет.** Проверять нечего: поведение, которое они описывали,
  больше не существует. Писать тест «в единственном языке счётчик совпадает с очередью» смысла мало —
  это следует из кода.
- **Задача закрыта без собственного кода.** Это соответствует её же приёмке («задачи не нужно, если
  E23 выполняется раньше»), но означает, что журнал E20 — это запись о закрытии, а не о работе.
