# E60 — Полезные слова в подборке «Учу»

## Спека

При равном ручном приоритете подборка по всем комнатам отдаёт места более полезным начатым словам.
Первая выдача новых слов учитывает полезность и дневную порцию. Когда освобождается место, полезное
отложенное слово возвращается раньше необязательного в той же группе. Ручной выбор, возврат забытых
слов и история повторений сохраняются.

## Что сделано

- Общая подборка для бота и Mini App учитывает полезность после ручного приоритета.
- При переполнении начатые слова с меньшей полезностью могут перейти в «В очереди» с прежним
  расписанием и прогрессом.

## Решения и ограничения

- Слово без оценки идёт наравне с меткой «Полезное», как в очереди новых слов. При равной
  полезности раньше идёт карточка, добавленная первой.

## Проверено

- Тест с подписанными запросами к Mini App проверил состав «Учу», попадание отложенного слова
  в повторы после освобождения места и ручную замену. Тесты также покрывают порядок новых слов и
  внеплановый возврат забытых слов с разной полезностью.
- Прошли `npm test`, `npm run typecheck`, `npm --prefix app run build` и `npm run docs:check`.
  Линтер прошёл с существующими предупреждениями React.
