# E48 — Разбор слов друзей в очереди Mini App

## Спека

Убрать отдельную колоду «Новые от друзей» и её счётчик. На первом показе неразобранного слова друга
после открытия перевода предложить «Учу», «Уже знаю» и «Не для меня» в режимах «Новые» и «Всё».
«Учу» начинает изучение и тратит место в дневной порции. Знакомое слово и отказ порцию не тратят.
Отказ убирает только свою карточку. Выбор можно отменить. Ранее сохранённые решения учитываются.

## Что сделано

- Слова друзей идут через обычную очередь с дневной порцией. Для первого решения открывается карточка
  с переводом даже при настройке только на диктант.
- Следующая карточка появляется после подтверждения решения сервером. При отказе сохранения текущая
  карточка остаётся открытой и выбор можно повторить.
- Удалены отдельный экран, счётчик и маршруты `/api/triage`. Обработка первого выбора идёт через
  обычный API ответа, отмена отказа возвращает слово через API управления словарём.

## Решения и ограничения

- «Учу» сохраняет первый ответ с коротким интервалом до повтора. «Уже знаю» использует существующую
  отметку знакомого слова без урона и без расхода дневной порции.
- Отказ удаляет только карточку текущего пользователя, если она всё ещё новая и у неё нет ответов.
  При отмене отказа карточка возвращается в обычную очередь с её порядком и дневной порцией.
- Сохранённые отметки из прежней колоды и из сообщения бота «Не знаю» читаются из существующего поля.
  Миграция базы не требовалась.

## Проверено

- `npm test`, `npm run typecheck`, `npm --prefix app run build` прошли. `npm run lint` прошёл с
  существующими предупреждениями React.
- Тесты API проверили оба режима очереди, учёт предыдущих решений, сохранение и отмену трёх вариантов,
  дневную порцию и защиту чужой или уже начатой карточки.
- В локальном Chrome с тестовой базой в памяти проверены тёмная тема на 390 px и светлая на 800 px,
  первый показ, длинный перевод, три решения, отмена отказа, пустая очередь, ошибки загрузки и
  сохранения. Использовались кнопки внутри страницы. Клиент Telegram на телефоне не проверялся.
