# E70 — Урон грамматики не списывает энергию

## Спека

Убрать грамматические удары из расчёта расхода с учётом старого формата записей. В новых записях
явно хранить нулевой расход и нанесённый урон. Оба формата должны учитываться в HP босса и в ленте.
Ставки и атаки на мобов продолжают расходовать энергию. Расчёт сверяется с данными продакшена.

## Что сделано

Старые записи о грамматике хранят нанесённый урон в поле расхода. Из-за этого они создавали
долг, который поглощал начисления за новые карточки. При расчёте трат такие записи пропускаются
по префиксу `grammar:`. Новые записи хранят нулевой расход и фактический урон в отдельных полях.

## Решения и ограничения

Остаток пересчитывается при чтении. История сохраняется в исходном виде, поэтому миграция
не нужна. Префикс выставляет сервис грамматики, а идентификаторы платных атак создаёт сервер боя.

## Проверено

- `npm test && npm run typecheck` прошли. Регрессия проверяет старые и новые удары по цели и в ленте,
  обе версии платной атаки на босса, расход на мобов и итоговый баланс.
- Запросом на чтение к продакшен-базе сверены начисления, фактические траты и ошибочно учтённый урон.
  Расчёт с исправлением возвращает положительный остаток для случая, о котором сообщили.
