# E56 — Пробный бой со Стражем за энергию

## Спека

Существующий личный запас отображается как энергия. В итогах занятия Mini App видны заработанная
энергия и переход к боссу. В одной комнате, указанной в конфигурации, ручной удар по Стражу стоит до
10 энергии. При открытом ядре игрок может ответить на вопрос по ранее показанному слову комнаты.
Удар за 10 энергии наносит 10 HP, за верный ответ до 13 HP. Попытка одна на игрока за текущего босса.

Обычный удар доступен. Вопрос оценивает сервер. Выход и устаревший бой сохраняют энергию.
Повтор запроса списывает её один раз. Удар попадает в общую ленту. В остальных комнатах действует
прежний бонус ядра.

## Что сделано

- Во вкладке босса личный запас виден как энергия. При включённом накоплении итог занятия показывает
  заработанную энергию и кнопку «К боссу».
- При открытом ядре «Ударить в слабое место» показывает четыре перевода рядом с обычной атакой. Выбор
  снимает HP и показывает разбор. Отмена возвращает к обычной атаке.
- Комната для пробы задаётся через `BOSS_ENERGY_TRIAL_ROOM_ID`. Переключатель накопления остаётся
  личным. Историю и баланс читает существующий боевой леджер.

## Решения и ограничения

- Вопрос берётся из слов комнаты с пройденными показами, использует отбор вариантов из дуэлей и живёт
  в памяти сервера пять минут. Для вопроса нужны четыре разных перевода. После перезапуска вопрос
  нужно открыть снова.
- Вопрос меняет урон. Расписание повторений ведёт обычная очередь. Руна применяется при обычном
  ударе, а для удара в слабое место доступен бонус за перевод.
- Выбор привязан к игроку, комнате, неделе и текущему Стражу. Расход и попытка записываются одним
  ударом. Повтор запроса возвращает результат сохранённого удара.
- Чтобы закончить пробу, убери переменную и перезапусти бота. Срок проведения пробы выбирает владелец.

## Проверено

- Прошли `npm test -- --silent`, `npm run typecheck`, сборка Mini App и линтер. Vite показал
  предупреждение о размере бандла, линтер показал существующие предупреждения React.
- Тесты с подписанным API проверили изоляцию комнаты, обе оценки, повторную отправку, обычную атаку
  и отказ после смены босса.
- В Chrome с тестовыми ответами API проверены итог занятия, переход на арену, успешный удар,
  отмена и сообщение об устаревшей атаке. Раскладка проверена при 390 px в светлой теме и 960 px в
  тёмной. На узком экране фокус переходит к вопросу, длинный вариант перевода переносится целиком.
  В живом Telegram проба ещё не проводилась.
