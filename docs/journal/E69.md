# E69 — Энергия автоматически за ответы

## Спека

Убрать отдельную настройку накопления. При включённом личном режиме босса новые ответы на карточки
пополняют запас автоматически. Отображаемая в занятии энергия берётся из подтверждённой записи
ответа. Существующие записи об уроне и энергии сохраняют назначение. Приёмка проверяет путь от
первой карточки до ставки, исчезновение переключателя и смену режима при открытой карточке.

## Что сделано

- Начисление записывает награду в запас по личному режиму босса. Величина берётся из действующей
  формулы ответа, включая усиления и затухание подряд идущих ошибок.
- Во вкладке босса виден запас и способ его пополнить. Учебный итог в Mini App показывает
  заработанную за занятие энергию, а итог в Telegram показывает доступный общий запас. Сервер
  возвращает начисленную энергию отдельным полем для свайпов, упражнений и диалогов. Анимация
  и итог занятия используют это поле для отображения ⚡.
- Запрос старого переключателя получает `410`. Пояснения в `/boss`, `/learn` и на арене описывают
  сбор энергии и отдельную атаку.

## Решения и ограничения

- Награда старой записи определяется её `review_logs.banked`. Поэтому прежний урон учитывается
  в текущем раунде, а ранее накопленную энергию можно тратить. Схема базы сохранила старое поле
  настройки для обратимости выкладки.
- Личный режим босса определяет начисление. Общий флаг `BOSS_ENABLED` по-прежнему управляет
  видимостью игры. Для уже открытых версий Mini App оставлены совместимые поля ответов API.

## Проверено

- `npm test`, `npm run typecheck`, `npm run lint`, `npm --prefix app run build` и `npm run docs:check`.
  Тесты подтверждают первый ответ при прежнем выключенном накоплении, отказ старой настройки,
  сохранение истории урона и запаса, начисление в Telegram и отмену ответа.
- В Chrome на 390 px в тёмной теме сыгран путь от пяти карточек до атаки за собранные 10 ⚡.
  До ставки HP составляло 15, после атаки стало 5. В уже открытой карточке отключение режима
  перед ответом не показало ложное начисление. На 800 px в светлой теме проверены загрузка, отказ
  и пустой запас. Проверка на телефоне внутри Telegram не проводилась.
