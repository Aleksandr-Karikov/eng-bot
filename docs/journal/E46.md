# E46 — Свайп-карточки занимают 14 мест из 20 в Mini App

## Спека

В смешанной очереди из 20 показов нужны 14 карточек слов, три задания на слух, один диалог,
один пропуск и один вопрос с вариантами. Упражнения распределяются по серии. В выборе учитываются
личные настройки, готовые материалы и число повторений. Приёмка покрывает полную и короткую очередь,
свободные места при недоступном упражнении и целевую тренировку. Проверки идут через подписанный API
и экран «Учить».

## Что сделано

- Упражнения стоят на местах 3, 6, 9, 12, 15 и 18. Подходящие слова подбираются среди всей пачки.
  Если одно слово подходит для нескольких упражнений, сервер по возможности находит замену для одного
  из них. Обычные карточки идут в исходном относительном порядке.
- Вопрос по ошибкам, если он готов во «Всё» или «Повторах», занимает место вопроса с вариантами.
  Иначе на этом месте может быть вопрос на сочетания. При добавлении вопроса по ошибкам полная пачка
  по-прежнему содержит 20 показов, а последнее незадействованное слово остаётся в очереди повторений.
- Если упражнение выключено или подходящего слова нет, его место занимает свайп-карточка.

## Решения и ограничения

- Короткая очередь использует те же интервалы в пределах доступной длины. Новые и необязательные
  слова сохраняют правила первого знакомства и узнавания. Если обе стороны свайп-карточек отключены,
  действует выбор из включённых форматов целевой тренировки.
- Состав зависит от подготовленных заданий. Диалог готовится при открытии и при отказе модели
  предлагает обычную карточку. Расписание FSRS определяет, какие слова попадают в пачку.

## Проверено

- `npm test -- --reporter=dot`, `npm run typecheck`, `cd app && npm run build`, `npm run docs:check` прошли.
- Через подписанный API проверены состав и интервалы полной пачки, готовность пропуска и вопроса
  на сочетания, общее место вопросов с вариантами, отсутствие дублей, выключенные упражнения,
  короткая очередь и целевая тренировка.
- В Chrome с подписанной тестовой сессией на 390 px в светлой теме пройдена вся серия и сверены оценки
  в журнале повторений. В тёмной теме на 390 и 800 px проверены переходы между карточками, диктантом
  и вариантами ответа. Проверены загрузка, завершение, пустая очередь и отказ авторизации.
  Озвучка и модель были подставными. Живой Telegram и продакшен в проверке не использовались.
