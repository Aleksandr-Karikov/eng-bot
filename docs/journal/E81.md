# E81 — Грамматика с открытой клавиатурой

## Спека

На телефоне вопрос, поле ответа и «Проверить» помещаются над клавиатурой (#28).
В сборке слово возвращается при тапе в предложении и в наборе (#29).
При новом открытии «Учить» Telegram получает адрес текущей сборки.

## Что сделано

Грамматика использует тот же расчёт видимого окна, что упражнения с вводом в карточках.
При открытой клавиатуре вопрос можно прокрутить внутри видимой области и отправить ответ тапом.
Состояние слов в наборе видно по подсветке, повторный тап возвращает выбранное слово.

Адрес открытия включает отметку времени сборки. Для HTML включена перепроверка при новом
запросе. Уже открытый WebView продолжает исполнять загруженную сборку до закрытия.

## Проверено

- Прошли `npm test`, `npm run typecheck`, сборка Mini App и линтер.
- В Chrome на ширине 320 px смоделировано видимое окно высотой 205 px с перекрытием нижней
  области. В прежней сборке кнопка оказывалась под перекрытием. В новой сборке тапы отправляют
  верный ответ в задании с пропуском и при ручном вводе предложения. Оба способа возврата
  слова проверены касаниями. HTML возвращает `Cache-Control: no-cache`.
- Проверка мобильного Telegram проводилась в эмуляции. Обращения #28 и #29 возвращены в
  открытые для сверки на телефоне пользователя.
