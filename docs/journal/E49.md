# E49 — Лимит одновременно изучаемых слов

## Спека

Ограничить количество одновременно изучаемых слов в личной очереди бота и Mini App. Новые слова по
всем комнатам ждут свободного места и остатка дневной порции. Приёмка покрывает смену суток,
освобождение места по FSRS, параллельный ответ на последнее место, сохранение повторений при уже
накопившейся очереди и понятное состояние ожидания в интерфейсе.

## Что сделано

- При десяти начатых словах очередь перестаёт предлагать новые. Когда одно слово переходит в
  выученные по существующему правилу FSRS, очередь может предложить следующее. Дневная порция
  ограничивает число первых ответов за день при подборе карточек и обновляется по поясу пользователя.
- Сервер перепроверяет свободное место в общей блокировке ответов. Карточка, которую успела открыть
  другая сессия, остаётся новой, если свободное место уже занято.
- Бот и Mini App объясняют, почему новые слова ждут. В словаре Mini App фильтр «Учу» показывает
  начатые слова, а «В очереди» — те, к которым ещё не приступили.

## Решения и ограничения

- Десять было стартовым пределом. [E50](E50.md) добавляет выбор предела в настройках.
  Уже начатые карточки приходят по расписанию и при большем числе.
  Если выученное слово вернулось в изучение, оно снова занимает место. «Уже знаю» оставляет
  карточку вне активной подборки до обычного повторения.
- Одно место может отобразиться на разных устройствах одновременно, пока карточки загружены
  заранее. Запись первого ответа резервирует место в существующем процессе бота.
- Состояния вычисляются из карточек и журнала ответов. Миграция данных не требуется.

## Проверено

- `npm test`, `npm run typecheck`, `npm --prefix app run build` прошли. `npm run lint` прошёл
  с существующими предупреждениями React.
- Тесты подписанного API и обработчиков бота проверили полную подборку после смены суток,
  освобождение места по FSRS, ответы из двух сессий, отказ на просроченной карточке диктанта,
  «Уже знаю» и повторения сверх лимита.
- В Chrome с тестовой базой в памяти проверены загрузка, ожидание новых, фильтры словаря,
  настройки, появление одного нового слова и ошибка API. Тёмная тема проверена на 390 px,
  светлая на 800 px. Проверка выполнена вне клиента Telegram.
