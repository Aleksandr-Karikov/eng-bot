# E53 — Продолжение после учебного лимита

## Спека

Когда обычная выдача упирается в дневную порцию или заполненную подборку, бот и Mini App объясняют
причину ограничения и показывают, как изменить его в настройках. Пользователь может взять ещё одну
карточку после предупреждения, что в длинной сессии слова могут запоминаться хуже. Ответ засчитывается.

## Что сделано

- Экран окончания сессии сообщает о сработавшем пределе, предлагает кнопку «Ещё одна карточка»
  и переход в настройки лимитов.
- Каждое нажатие даёт одну карточку с переводом. Можно повторить отложенное слово или начать новое.
  Кнопка снова доступна, пока есть карточки сверх плана.
- Обычное ограничение сверяется при сохранении первого ответа. По явному выбору сохраняется
  сверхплановый ответ и обновляется расписание. При заполненной подборке прогресс остаётся в очереди
  начатых слов. Отмена восстанавливает прежнее расписание и место карточки.

## Решения и ограничения

- Бот выбирает доступное отложенное повторение перед новым словом. Mini App учитывает выбранный режим.
  Карточка вне обычной очереди появляется по одному явному нажатию.

## Проверено

- Прошли `npm test`, `npm run typecheck`, `npm --prefix app run build` и `npm run docs:check`.
  Линтер прошёл с существующими предупреждениями React.
- Через подписанный API проверены дневная порция, сохранение ответа сверх неё и обычный ответ при
  исчерпанном пределе. Через обработчики бота проверены предупреждение, ссылка на настройки,
  сверхплановое повторение, его отмена и повторная оценка.
- В Chrome с тестовой базой проверены загрузка, сообщение о заполненной подборке, переход в настройки,
  ошибка загрузки с повторной попыткой, зачёт одной карточки и сообщение о дневной порции. Тёмная тема
  проверена на 390 px, светлая на 800 px, вне клиента Telegram.
