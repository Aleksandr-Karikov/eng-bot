# E50 — Личный предел одновременно изучаемых слов

## Спека

Пользователь может задать предел одновременно изучаемых слов в /settings и Mini App. Доступны
10, 15, 20 и 30 слов, по умолчанию 15. Изменение сразу применяется к общей очереди. Снижение
предела сохраняет расписание начатых карточек. Дневная порция учитывается отдельно.

## Что сделано

- В боте появился пункт «Слов одновременно», в Mini App он находится в разделе «Активное обучение».
- Бот и Mini App сохраняют одно личное значение. Сервер принимает только варианты из настроек.
- Миграция `0065_equal_microbe.sql` добавляет колонку с пределом 15 для новых и существующих
  пользователей.

## Решения и ограничения

- Смена предела и первый ответ на новую карточку используют общую блокировку записи. При снижении
  предела следующая новая карточка ждёт, пока число начатых слов станет ниже выбранного значения.
- В [E51](E51.md) предел стал ограничивать состав подборки, а отложенные слова сохранили прогресс.

## Проверено

- `npm test`, `npm run typecheck`, `npm --prefix app run build` прошли. `npm run lint` прошёл
  с существующими предупреждениями React.
- Через обработчики бота и подписанный API проверены повышение и снижение предела, отказ для
  произвольных значений, прежняя дневная порция и доступность начатых карточек.
- На базе в памяти со схемой до миграции существующий пользователь получил предел 15 и сохранил
  свою дневную порцию.
- В Chrome с тестовой базой в памяти проверены тёмная тема на 390 px и светлая на 800 px, выбор и
  сохранение значения, изменение очереди и отказ загрузки. Проверка выполнена вне клиента Telegram.
