# E80 — Напоминание о заданиях дня в полдень

## Спека

Писать в личку в 12:00 по часовому поясу пользователя, если остались задания дня.
Кнопка в сообщении открывает задания Mini App. Час напоминаний о карточках определяется
существующей настройкой.

## Что сделано

Рассылка заданий использует отдельную дату отправки в `users`. Миграция
`0070_daily-tasks-notice-date.sql` добавляет поле к существующим пользователям.
После успешной доставки в тот же день сообщение не повторяется. При сбое бот пробует ещё
раз до 13:00. Час заданий указан в настройках рядом со временем карточек.

## Проверено

- Прошли `npm test`, `npm run typecheck`, сборка Mini App и линтер.
- Тесты рассылки покрывают разные часовые пояса, отсутствие карточек, время и ссылку,
  повтор при сбое и отсутствие догоняющего сообщения после 13:00.
- В Chrome на 320 px видно полуденное время заданий рядом с выбранным часом карточек.
- Миграция прошла на копии снимка продакшена. Существующие значения времени и дат
  напоминаний о карточках сохранены. Доставка проверена с тестовым получателем.
