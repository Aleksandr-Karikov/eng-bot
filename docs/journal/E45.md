# E45 — Слово видно в диалоге, перевод скрыт до подсказки

## Спека

После проверки [E44](E44.md) явно указываем слово, которое нужно употребить. В Mini App и `/learn`
перевод и начало реплики открываются по запросу. При неудаче разбор показывает возможный ответ
с этим словом в той же ситуации. В Mini App первую попытку можно перефразировать.

## Что сделано

- Под репликой собеседника видно слово в словарной форме. «Подсказка» в Mini App и спойлеры в
  `/learn` открывают перевод и начало возможной реплики.
- Проверка учитывает и вопрос собеседника, и употребление заданного слова. Если ученик ответил по
  смыслу другой фразой, разбор признаёт, что реплика подходит, и предлагает попробовать с указанным
  словом. Первая попытка в Mini App даёт повторить ответ до записи оценки.
- После проверки незачтённого ответа показывается вариант «В этой ситуации» с целевым словом.
  «Не знаю» без ввода в Mini App показывает перевод и пример из словаря без запроса к модели.

## Проверено

- `npm test -- --reporter=dot`, `npm run typecheck`, `cd app && npm run build`, `npm run docs:check` прошли.
- Через подписанный Mini App API проверили повторную попытку и разбор реплики про субботнюю смену
  с `tough` в той же сцене. Через тестовый Telegram API проверили, что слово видно, а перевод скрыт
  под спойлером.
- В Chrome на 390 px в обеих темах и на 800 px в тёмной проверили показ слова, подсказку, повторную
  попытку, контекстный вариант и ввод с имитацией клавиатуры. Использовалась тестовая модель.
