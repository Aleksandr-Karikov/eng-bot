# E73 — Начисление энергии видно после последней карточки

## Спека

Всплывающая награда за подтверждённый ответ доигрывает при догрузке очереди и на экране итога.
Поддерживаются быстрые свайпы, оценка кнопкой, отмена и системная настройка уменьшения движения.

## Что сделано

При временно пустой очереди CSS скрывал слой награды. Слой теперь виден при смене состояния,
сохраняет позицию и размещается над нижней панелью. При переключении режима всплывающие числа
предыдущего занятия убираются вместе с его итогом.

## Решения и ограничения

Motion продолжает показывать подтверждённую сервером сумму поверх экрана без задержки в выдаче
карточек. При уменьшенном движении число плавно появляется и исчезает на месте.

## Проверено

- Прошли `npm test`, `npm run typecheck` и `npm --prefix app run build`.
- В Chrome с эмуляцией Telegram при 390 px в тёмной теме воспроизведён исходный сбой. После правки
  проверены свайпы и кнопка оценки в быстрой серии, задержка подтверждения, догрузка и видимый
  итог последнего ответа. Движение проверено с замедлением CPU.
- В светлой теме при 800 px проверены отмена, уменьшенное движение, сброс при смене режима
  и отсутствие награды с выключенным режимом босса.
- Последние записи свайпов на проде проверены в режиме чтения. Начисления присутствовали в базе.
