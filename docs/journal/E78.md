# E78 — Открытие ответа на карточке

## Спека

Оставить одно видимое действие «Показать ответ» там, где появится перевод. Ответ открывается
тапом и с клавиатуры в обучении и предпросмотре. В обучении после раскрытия доступна оценка.

## Что сделано

Кнопка с глазом стала кнопкой «Показать ответ». Она раскрывает перевод прямо на карточке.
Нижняя панель появляется для оценки после раскрытия. Тап по вопросу тоже открывает ответ.

## Проверено

- В Chrome проверены тап и видимость длинного перевода в тёмной теме на ширине 320 px,
  Enter и пробел на ширине 800 px в светлой теме, сброс при переходе к следующей карточке
  и предпросмотр без оценки. После раскрытия оценка отправляется с панели Mini App
  и через эмулированное событие нативной кнопки Telegram.
- «Показать вариант» в переводе открывает образец через API.
- Прошли `npm test`, `npm run typecheck`, `npm --prefix app run build` и `npm run lint`.

Исходный сбой на клиенте Telegram не воспроизведён. Для раскрытия теперь используется
кнопка внутри Mini App.
