# E42 — Исправления по ревью E38–E41

## Спека

В тренировке по ошибкам перевод открывается по кнопке. Добавляется слово и комната из показанного
черновика, с теми же квотами, что в `/add`. Незнакомый правильный вариант можно перевести и добавить
после ответа. На карточке Mini App «Не знаю» работает без ввода. Для нескольких пропусков требуется
ответ по порядку, а словарная форма сама по себе не считается точным ответом.

При сбое проверки вопроса сочетания сохраняются. Скрипты проверки вопросов и исправления объяснений
пропускают записи, которые успели изменить после чтения. Приёмка включает проектный гейт.

Связанные задачи — [E38](E38.md), [E39](E39.md), [E40](E40.md) и [E41](E41.md).

## Что сделано

- «Что такое…?» использует подготовку черновика `/add`. Черновик привязан к пользователю и комнате.
  Можно ответить на вопрос, перейти дальше и сохранить ранее показанное слово. В разборе появляется
  перевод незнакомого правильного варианта. До ответа подсказка относится к словам предложения.
- Mini App отправляет «Не знаю» даже с пустыми полями. Для «Проверить» в задании с несколькими
  пропусками нужно заполнить каждое поле. Общая быстрая сверка принимает ответы по порядку с `|`
  или в одной строке через пробел. Словарная форма остаётся допустимой для одного пропуска.
- Таймаут и неразбираемый ответ проверяющей модели сохраняют список сочетаний без вопроса.
- Скрипты сравнивают прочитанные значения и обновляют слово одной операцией. Изменённые записи
  пропускаются и отдельно учитываются в итогах прогона.

## Решения и ограничения

- Для подсказки действует обычный черновик `/add`, включая квоту подготовки, возможность исправить
  перевод и отмену. Если открыть новый черновик, предыдущий перестанет действовать.
- Если правильный ответ содержит незнакомое слово, бот оставляет разбор с кнопками перевода
  и «Дальше». Слово определяется по словарю личной или привязанной к чату комнаты и сохраняется
  с заполненным предложением в поле «Где встретилось».
- Сбой проверки отбрасывает вопрос для этой генерации. Сочетания остаются доступны для изучения.

## Проверено

- `npm test -- --reporter=dot`, `npm run typecheck`, `cd app && npm run build` и
  `npm run docs:check` прошли.
- Через тестовый Telegram API проверены перевод по нажатию, правильный вариант в разборе, сохранение
  черновика после смены вопроса и комнаты, расход квот и отказ без запроса к модели.
- Через Mini App API с подписанными тестовыми данными проверено, что «Не знаю» раскрывает оба
  пропуска и записывает оценку «Забыл» без запроса к модели.
- В локальном Chrome с тестовой сессией Telegram проверены загрузка и карточка с двумя пропусками
  при 390 px в тёмной теме и одним пустым пропуском при 900 px в светлой. «Не знаю» раскрыло ответ
  и записало одну оценку на каждом экране. Частично заполненная карточка дождалась завершения ввода
  при нажатии «Проверить». Разбор и «Дальше» поместились по ширине.
- Оба скрипта проверены на временных базах с подставным провайдером. Свежая правка во время запроса
  к модели сохранилась, неизменённая контрольная запись обновилась.

Живой Telegram, реальные провайдеры и продакшен в этой проверке не использовались.
