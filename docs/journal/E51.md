# E51 — Управляемая подборка «Учу»

## Спека

Список «Учу» показывает личную подборку по всем комнатам и число занятых мест. При большом
накоплении часть начатых слов ждёт свободного места с прежним прогрессом. В Mini App можно взять
слово из очереди и, если подборка заполнена, выбрать одно слово на замену.

## Что сделано

- Бот, Mini App, напоминания и прогноз используют одну подборку для повторений с зачётом.
  Выученные слова приходят по расписанию.
- В Mini App путь к замене проходит через «Слова → Учу → Выбрать слово из очереди». На странице
  входящего слова кнопка «Взять в обучение» предлагает выбрать, какое из активных отложить.
  Фильтр «В очереди» показывает новые и отложенные слова текущей комнаты.
- Замена обновляет порядок обеих карточек за один запрос. Записи FSRS, даты повторения и история
  ответов сохраняются. Отложенное слово можно взять обратно тем же способом.

## Решения и ограничения

- Начальный состав берётся из уже начатых слов в порядке добавления карточек. Ручной выбор идёт
  первым, заменённое слово уходит в конец очереди начатых. Когда освобождается место, сначала
  возвращаются начатые слова.
- Ручной выбор нового слова занимает место сразу. Его первая оценка по-прежнему учитывает дневную
  порцию при выдаче карточки.
- Миграция `0066_lethal_jack_flag.sql` добавляет порядок карточки с исходным значением. Имеющиеся
  поля FSRS сохраняются.

- Прошли `npm test`, `npm run typecheck`, `npm --prefix app run build` и `npm run docs:check`.
  Линтер прошёл с существующими предупреждениями React.
- Через подписанный API проверены замена в заполненной подборке, возврат отложенного слова,
  автоматическое заполнение при освобождении места, выученные повторы и отказ для чужих слов.
  До и после замены сверены расписание, состояние FSRS и история ответов.

  800 px, загрузка и пустой поиск, отмена замены, ошибка, сохранение и повторное открытие списка.
  Проверка выполнена вне клиента Telegram.
