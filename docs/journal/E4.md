# E4 — Честность наказывается: «Забыл» повышает цель следующей недели

## Спека

`raw` в `roomReviews` считал все ответы подряд, включая `again`. Ошибки раздували цель следующей
недели, поэтому врать «Помню» было выгоднее, чем признаться.

Приёмка: цель растёт только от ответов, отражающих прогресс, либо правило названо явно; тест покрывает
неделю с преобладанием `again`.

Решение владельца: вместе с E3 цель перестаёт считаться от числа ответов, поэтому `raw` больше не
участвует — правку делать в той же ветке.

## Что сделано

Правка сделана в одной ветке с E3, потому что обе задачи меняют одну формулу (`goalProgress`).

- `src/services/goals.ts` — цель недели больше не читает прошлую неделю вообще: `DEFAULT_GOAL_HP` или
  явная настройка комнаты. Счётчик `raw` удалён из `roomReviews` вместе с вопросом «сколько было ответов».
  Это закрывает E4 не заплаткой («не считать `again`»), а снятием самой зависимости: теперь никакие
  оценки прошлой недели на цель не влияют, включая «Забыл».
- `tests/goals.test.ts` — тест «прошлая неделя с преобладанием «Забыл» не раздувает цель»: 200 ответов
  `again` на прошлой неделе дают цель 100 HP, а не 440.
- `docs/architecture.md` — причина названа в абзаце о фиксированной цели.

Переиспользованное решение записано в [E3.md](E3.md): там же замеры и обоснование числа 100.

## Решения и причины

- **Снятие зависимости, а не фильтр по рейтингу.** Прямое исправление E4 — исключить `again` из `raw`
  или считать только «Помню»/«Легко». Но при сделанной E3 `raw` вообще не нужен, и фильтр оставил бы
  механизм на месте: следующая правка могла бы снова начать считать цель от ответов, и дефект вернулся
  бы вместе с ней. Удаление входа надёжнее точечного условия.
- **Прошлая неделя не читается вовсе.** В `goalProgress` больше нет запроса за предыдущую неделю, то есть
  на один запрос к базе меньше на каждый вызов `/goal`, `/boss`, трофеи и дайджест.

## Проверки

```
npx vitest run tests/goals.test.ts  → 6 tests passed
npx vitest run                      → 119 files, 834 tests passed
npx tsc --noEmit                    → чисто
```

Тест на старом коде падает по существу: `expected 440 to be 100` — 200 честных «Забыл» раздували цель
в 4.4 раза.

## Известные ограничения

- **Исторические недели не пересчитаны.** Уже прошедшие недели остались с теми целями, которые были
  посчитаны тогда. Это осознанно: `/goal` за закрытую неделю показывает то, что человек видел.
- **«Забыл» по-прежнему влияет на урон через затухание (E2), и это правильно.** Цель недели от оценок
  не зависит, но сам урон за серию провалов падает — там наказывается не честность, а прокрутка одной
  карточки.
