# Босс: план исправлений и передачи работы

Запрос: исправить результаты ревью коммитов e739e67…cec84ea; сделать экономику понятной без магазина с одним товаром; показывать нанесённый урон при ответах в Mini App.

## Решения

- Магазин предлагает три усиления: сила, слух и письмо. Старое единственное усиление сохраняется как сила. Это уточнение пользователя после первой реализации.
- +10% должно работать с первого уровня. Урон хранить с точностью до десятых HP; округлять только представление, избегая ошибок floating point.
- Урон ответа фиксировать при записи review_logs. Старым записям без снимка считать базовый урон без усилений: исторический уровень неизвестен. Покупки не пересчитывают прошлое.
- Прогресс, лента, монеты и трофеи используют одинаковый урон. Учитывать отмену, stale и practice (вне зачёта не наносит урон).
- Удалить из публичного каталога трофеи без реализации. Исторические записи не удалять. Исправить добивающий удар, участников и условия выдачи.
- После победы учёба продолжается: показать срок следующего босса, монеты и доступные награды. Условия трофеев доступны по нажатию на телефоне.

Бонусы складываются от базового урона, действуют только на будущие ответы и остаются навсегда. Старое усиление сохраняется как «Сила».
