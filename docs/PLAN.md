# План проекта

Добавляй задачу, когда появится требование к проекту. Открытая строка содержит спеку, приёмку и
текущее состояние; после завершения подробности переносятся в `journal/E<номер>.md`. Номер не
переиспользуется. Создавай следующий свободный `E<номер>`.

Формат открытой задачи:

```md
- [ ] **E1** — Название. **Спека:** цель, сценарий, состояния, данные и права (если применимо). **Приёмка:** наблюдаемый результат и необходимые проверки. ➡️ **Сейчас:** что известно, что мешает, следующий шаг.
```

Правила ведения — в [CONTRIBUTING.md](CONTRIBUTING.md). Индекс [INDEX.md](INDEX.md) генерируется
командой `npm run docs:index`; руками его не правь.
