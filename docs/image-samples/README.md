# Образцы картинок: сравнение моделей

Сгенерировано боевым конвейером бота: слово → `buildImagePromptPrompt` (Gemini Flash Lite) →
описание сцены → модель-рисовалка + стиль. Сжатие как в проде (`sharp`, 512 px, JPEG q82).

Слова специально с переносными смыслами: `set off` (отправиться в путь), `gauge` (оценивать),
`bank` (берег).

## Что видно

**Размер у API не квадратный.** Gemini отдаёт **1408×768**, локальный FLUX отдавал 512×512
(проверено 4 вызовами). `compressPicture` жмёт по `fit: "inside"`, поэтому карточка выходит
**512×279** — шире и ниже прежней. Для Telegram это нормально, но вид карточки меняется.
Образцы здесь уже в этом размере.

**Локальный FLUX — заметно слабее.** На `gauge` он не понял задачу: женщина смотрит на мужчину
«изучающе», но мимика читается как недовольство, поза неестественная. На `set off` человек вылезает
из каменного портала вместо двери коттеджа. FLUX рисует «картинку по словам», не понимая смысла.

**Gemini понимает сцену.** `set off` — рюкзак, карта, рассвет, дверь; `gauge` — именно изучающий
взгляд; `bank` — граница воды и берега. Стиль комикса держится ровно, красный акцент один.

**Дешёвая 3.1-flash-lite не хуже дорогой 2.5.** Композиция чище, лишних деталей меньше.
Дорогая 3.1-flash-image за $0.067 — больше «глянца», для карточки это не преимущество.

**Акварель читается лучше комикса.** Мягче и понятнее для запоминания; комикс с halftone
на 512 px даёт грязь в тенях. Стиль решено сменить на акварель.

Менять надо только умолчание — `DEFAULT_IMAGE_STYLE = STYLE_PRESETS[1].style`
(`src/images/images.ts:62`). Порядок `STYLE_PRESETS` переставлять нельзя: индекс стиля уходит
в callback data кнопки «Перерисовать» (`src/bot/handlers/mnemonic.ts:143`), и старые кнопки
в уже отправленных сообщениях начнут рисовать не тот стиль. `tests/redraw.test.ts:63` тоже
жмёт `STYLE_PRESETS[1]`. Детали — в `docs/scaling-plan.md`, раздел про стиль.
