name: repo-review-fix
description: Проверить исправления после ревью по списку находок, не повторяя полный аудит. Используй после правки по замечаниям; широкую починку передай на полное ревью.
---

Возьми дословный список находок и дифф исправления. По каждой проверь исходный сценарий, причину и изменённые строки; где дёшево, выполни тест, который краснел бы при возврате ошибки. Назови «закрыта / не закрыта» с конкретным доказательством. Ищи новые блокеры только в изменённых строках и их вызовах.

Если починка расширилась на новый модуль, контракт или много строк, вернись к полному `repo-review`. Не объявляй замечание закрытым по одному зелёному гейту, если его сценарий не проверен.
