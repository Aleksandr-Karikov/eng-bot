name: repo-progress
description: Составить проверяемую сводку прогресса проекта из плана, журналов и Git. Используй для статуса, отчёта владельцу или подготовки доски задач.
---

Возьми актуальный индекс и план проекта; генерируемый индекс не правь вручную. Для плана со строками `- [ ] **E1**` начни с `npm run docs:check` (он же сверяет индекс с планом) и посчитай задачи разбором `docs/PLAN.md`; отдельного снимка статуса в проекте нет. Закрытые задачи проверь по журналам, а задачи в работе — по блоку `➡️ **Сейчас:**` и Git. Раздели завершённое, открытое, припаркованное и заблокированное; зависимость проверяй по тексту задачи, а не по значку. Для чисел укажи источник и дату среза.

Верни короткую сводку, следующие важные блоки, блокеры и проверки, которым ещё нет подтверждения. Если индекс расходится с планом, назови расхождение и проектную команду его обновления. Внешняя доска требует отдельного адреса и механизма записи; без них подготовь сводку локально и не объявляй её опубликованной.
