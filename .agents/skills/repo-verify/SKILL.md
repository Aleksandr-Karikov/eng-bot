description: Прогнать проектный гейт и дать короткий точный отчёт о результатах. Используй перед завершением содержательной правки или когда пользователь просит проверить проект.
---

Возьми команду общего гейта и дополнительные проверки по затронутым путям из проектного `AGENTS.md`. В eng-bot это `npm test && npm run typecheck`, при правке Mini App — ещё `cd app && npm run build`, при правке плана — `npm run docs:index && npm run docs:check`. Запусти их один раз на текущем дереве. Кэша результатов в проекте нет, поэтому неизменное дерево повторно не гоняй без причины.

Зелёный результат назови с точной командой и числом тестов, если оно известно. Для каждого красного шага дай его имя, путь и дословный фрагмент ошибки, который позволит исправить причину; полный лог не вставляй. Локальные прогоны тестов слушают localhost: если параллельно идёт второй `npm test` или запущен бот, часть тестов упадёт на занятом порту — отдели это от ошибки правки и не выдавай за проверенный код. Отдельно назови отказ окружения и проверки, которые не удалось выполнить. Не правь код ради зелёного отчёта без задачи.
