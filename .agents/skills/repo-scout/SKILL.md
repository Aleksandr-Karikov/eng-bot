Код и план на этом шаге не правь. Найди задачу в `docs/PLAN.md` (или `docs/INDEX.md`) и начни с `npm run context E<номер>`; строку читай целиком, включая `➡️ **Сейчас:**`, но большой документ открывай окнами. Проверь статус, блокеры и связанные задачи. Для закрытых задач открой `docs/journal/E<номер>.md`: тело могло уйти из плана.

Прочитай только относящиеся к задаче решения и спецификацию, найди похожий код и свежую историю затронутых файлов (`git log --oneline -- <путь>`). Утверждения документа о текущем поведении проверь по коду. Назови инварианты `AGENTS.md`, которые заденет работа. Исторические разборы (`docs/boss-next-plan.md`, `docs/superpowers/`) — источник контекста, а не текущее описание кода.

Верни компактно: строка задачи и статус; блокеры и решения; что уже реализовано с путями; нужный фрагмент спецификации; открытые развилки. Не пересказывай большие файлы: этот ответ попадёт в контекст следующего шага.
